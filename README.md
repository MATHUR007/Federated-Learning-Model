Federated Learning CIFAR-10 Project
This project compares three federated learning setups on CIFAR-10:
FedAvg baseline across multiple Dirichlet alpha values.
Clustered FedAvg with delayed clustering warm-up.
Personalized clustered FL with per-client evaluation.

Supporting modules:
data/load_data.py loads CIFAR-10.
datasets/partition.py creates Dirichlet non-IID splits.
datasets/client_dataset.py builds client dataloaders.
models/cnn.py defines the CNN.
train/local_train.py handles local client training.
server/fedavg.py performs weighted averaging of model parameters.
clustering/client_similarity.py, 
clustering/kmeans_cluster.py, and
clustering/group_clients.py handle clustering.

Report interpretation notes
Use the final summary table to report the following findings:
FedAvg improves as alpha increases.
The delayed clustered method performs close to FedAvg in the current setup.
Personalized clustered FL shows much lower overall accuracy, but the per-client metrics
show a wide spread, which is important to discuss in the dissertation.
The delayed clustering experiment should be presented as a test of the hypothesis that
clustering too early may hurt performance, not as a proven explanation unless additional
ablations are run.

Notes for reproducibility
Use the same random seeds for all main experiments.
Keep architecture, batch size, communication rounds, and local epochs identical across
methods when making final comparisons.
If any alpha value changes in the code, regenerate all related CSVs and plots before writing
the report.
Keep the generated CSVs and figures for dissertation appendices and viva preparation.
